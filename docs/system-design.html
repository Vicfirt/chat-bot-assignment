System Design

Agentic RAG Tax Chatbot

A LangGraph agent that answers U.S. federal individual income-tax questions grounded in IRS Publications 17, 501 and 505, and computes tax with a deterministic calculator — never the model. One FastAPI process hosts the graph and an embedded vector store; the only external service is a local LLM.
